# P0-T06 — Verify Coach truthfulness and no silent mock

**Date:** 2026-09-05  
**Local verdict:** PASS  
**Independent verification:** PASS

## Root cause and scope

The browser client sent schema version `v1`, while the Vercel and Express adapters required `coach.v1`; real requests therefore returned 400 and silently fell back. The client also inferred “LLM available” from the presence of `/api/coach`, and basic output could be attributed to Stockfish from FEN alone. The fix is limited to the existing shared endpoint, strict response validation, response-derived disclosure, and regression tests. No dependency, provider, model, storage, credential, theme, or layout changed.

## Implementation

- Unified the client, Express adapter, and Vercel adapter on `coach.v1` and `POST /api/coach`.
- Rejected missing/legacy request versions and untrusted response shapes.
- Made deterministic fallback report `source: basic`, `engineSource: none`, and `knowledgeSource: none`.
- Derived the visible source from the actual response. Basic output is labeled `Diễn giải cơ bản` and `Nguồn: Diễn giải cơ bản · Không dùng AI`; only `source: llm` can show the AI source label.
- Classified `src/services/mockCoachService.ts` and `server/services/aiCoachService.js` as dormant: neither has a production importer and neither identifier appears in the fresh production bundle.
