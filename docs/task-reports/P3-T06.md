# P3-T06 — Retry workflow

Status: **VERIFIED** — independent PASS.

## Outcome

- A wrong move stays off the board and retry resets the original real-puzzle position.
- Wrong, retry, intermediate-correct, and final-correct events stay under one attempt ID until the puzzle is solved.
- Resetting a solved puzzle emits no event by itself and the next played line receives a new attempt ID.
- The real-corpus Next action advances to different puzzles and only wraps after exhausting the available list.
- Retry and intermediate events remain non-scoring; solved-attempt persistence and reload remain byte-exact.
- Production behavior already met the contract, so this task added regression coverage without changing source code.
