## Defects reproduced and fixed

The production hook created an `AbortController` but never passed its signal to the bot or engine, so confirming a new game left the old Stockfish search alive. Its shared timeout ref also allowed a stale request's `finally` to clear a newer request's timer. The RED Chromium regression observed no terminated worker after new-game.

Each request now owns and forwards its controller and timer. Cancellation invalidates the hook generation; `botService` rethrows aborts instead of fabricating a fallback move; `stockfishService` terminates the captured worker, rejects the cancelled analysis, and keeps the serialized queue usable. `ChessGameBoard` cancels on context bot-generation changes before starting any replacement request.

No dependency, provider, model, storage, schema, UI design, or production timeout value changed.
