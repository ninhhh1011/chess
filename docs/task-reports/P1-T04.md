## Defect and minimal fix

The parser loaded a PGN with chess.js, then reset the game and re-tokenized movetext with regular expressions. That discarded SetUp/FEN state, treated variation tokens as mainline moves, and derived incorrect ply numbers from non-move tokens.

The custom tokenizer was deleted. `replayPgn` now returns chess.js verbose mainline history directly, maps comments by FEN, uses each move's `after` FEN, and assigns contiguous ply numbers. No dependency, provider, model, storage, or schema changed.
